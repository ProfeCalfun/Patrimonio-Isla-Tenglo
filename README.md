# Guardianes del Patrimonio de Isla Tenglo

Sitio estático listo para GitHub Pages.

## Archivos
- `index.html`: portada del proyecto.
- `cruz.html`: Cruz de Tenglo.
- `embarcadero.html`: conectividad y embarcadero.
- `conchales.html`: conchales arqueológicos.
- `arqueologico.html`: sitio arqueológico de Puntilla Tenglo.
- `escuela.html`: Escuela Rural Puntilla Tenglo.
- `styles.css`: estilos de las páginas interiores.

## Publicación en GitHub Pages
1. Crear un repositorio público en GitHub.
2. Subir todos los archivos manteniéndolos en la raíz del repositorio.
3. Ir a **Settings > Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar `main` y carpeta `/ (root)`.
6. Guardar. GitHub entregará una URL del tipo `https://usuario.github.io/repositorio/`.

## Recomendación
Reemplazar gradualmente las imágenes externas por fotografías propias del proyecto. Así el sitio tendrá más identidad local y no dependerá de servidores de terceros.
